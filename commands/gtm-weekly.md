# GTM Weekly

Run the **`iterate-gtm-weekly`** skill: pull Visit → Signup → Activated →
Habit → Paid → Refer by source for this week vs last, fill any launch
Results table older than 7 days, name the step with the largest absolute
loss, attribute last week's experiment with a number, choose exactly one
experiment and one post, append the scorecard row, schedule next week.

Production errors go to `iterate-post-launch`; blind funnel cells go to
`audit-analytics` first.

The full playbook lives in the **`iterate-gtm-weekly`** skill.
