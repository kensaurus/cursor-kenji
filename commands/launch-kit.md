# Launch Kit

Run the **`docs-launch-kit`** skill: build a claims table from the changelog
and repo, pick one problem-first angle, write native copy per channel, add a
calendar and UTM links, and save it as `docs/launch/<version>.md`.

Every number and feature in the copy must trace to the claims table. No vote
solicitation, no fabricated proof, maker disclosed on every channel.

The full playbook lives in the **`docs-launch-kit`** skill.
