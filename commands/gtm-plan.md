# GTM Plan

Run the **`plan-gtm`** skill: inventory how the repo is sold today
(monetization model, positioning, activation path, analytics, SEO/AEO,
distribution assets), interview the founder one question at a time, then emit
`plan-gtm.md` with a positioning statement, monetization verdict, funnel table,
channel plan, and a phased burndown. **Plan only — change nothing until each
phase is approved.**

After approval, execute with `workflow-gtm` (or the single skill a phase
names: `enhance-web-conversion`, `enhance-onboarding`, `enhance-web-seo`,
`docs-launch-kit`).

The full playbook lives in the **`plan-gtm`** skill.
