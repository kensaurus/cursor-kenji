# /readability

Follow the **`enhance-readability`** skill. Comprehension first: measure text,
then grouping / deadspace / icons, then generate a table or diagram only if it
lowers cognitive load. Looks-good → `enhance-web-ui`. Breakpoints →
`audit-responsive`. WCAG floor → `audit-accessibility`.
