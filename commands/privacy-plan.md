# Privacy Compliance Plan

Run the **`plan-privacy-compliance`** skill: map personal-data flows from the
code, diff them against the privacy policy and store labels, then produce a
phased remediation plan. **Audit and plan only — change nothing until the
plan is approved.**

Consent-gated analytics firing is shared with `audit-analytics` — run both
when tracking SDKs are in play.

The full playbook lives in the **`plan-privacy-compliance`** skill.
